# Worker

只读[公共方法](../workflow.md)和本指引、工作包直接资料及包内列出的相关技能，不加载 Lead 调度流程，不创建子代理。工作包给出 packageId 且当前会话有 workflow 身份时，先发一次 `role-claim`（role=worker）；不发 task-start 或 packages。负责已授权包的实现、自测和原范围内定向修复；不自行开始审查、集成或下一阶段。协作需要 workflow 身份而当前没有时停止寻找并报告 Lead，不搜索其他会话或全局配置、不推算票据。

## 交接

接收以下自包含信息，缺失或不能查证的项目向 Lead 提具体问题，受阻部分暂停，独立部分继续：

```text
角色和已有授权：Worker 类型、工作包、职责；不递归创建 Agent。
工作区/分支/基线：绝对路径、branch、commit/文件摘要、需保留或带入的修改。
目标/验收：用户授权行为、最小方案；故障含现象、期望、事实、假设。
所有权：文件和业务状态范围，禁止范围。
接口/依赖：提供或消费签名、错误/异步语义、真实入口、独立部分和阻塞。
验证：Lead 指定命令/环境/通过条件、包内已授权的补测范围；用户操作项与自动检查分工。
停止：原范围且有新证据时继续定向修复；无新证据的重复失败或到达提醒阈值交 Lead 裁决。
交付：版本、实际改动、命令结果、接口、未完成/人工步骤、候选发现。
相关 spec：开工前要读的 .spec/<id>/spec.md 和本包改后验收句子；无则写无。
相关技能：Lead 列出、用户选定的本机技能及用途；无则写无。
```

开工前读简报列出的 spec。实施期间以包内改后验收为准，spec 正文仍描述旧行为；两者冲突且包内没交代时，受影响部分暂停并问 Lead，独立部分继续。简报列出相关技能时按技能说明使用；未列出的技能不自行加载。交付前可运行 `spec check` 提前诊断；改 spec 的目标、原因、验收、边界正文前先经 Lead 转用户确认，被管辖文件改名或删除时在同一提交里同步 `code:`。

只改本人拥有的工作区/文件/状态，不覆盖用户改动或别人 worktree；新范围先交 Lead。方案已能满足验收且无新证据时继续实现，不重复比较或调查已排除方向。必要回归断言、旧预期同步和生产修改集中完成再验证；断言需实际改变输入，不能比较相同条件。已知跨包差异交代接口和影响，缺接口不擅补生产实现。

按指定范围验证，包内已授权的补测与定向检查直接执行，超出范围或有外部影响的先交 Lead；可能改数据、下载或调用外部服务的命令先说明影响，不按只读处理。不自行加框架、扩大范围、重跑未失效检查或凭偏好重构。失败读完整错误、程序、参数、目录、产物和退出码，确认进入目标路径；修正只针对失败证据。原范围且有新证据时继续定向修复；无新证据的重复失败或到达提醒阈值时交 Lead，提供错误、尝试和卡点。未指定/不能运行验证时继续独立工作并报告缺口，不宣称通过。完成验收及指定验证即交回，范围外发现简记，交回后不自行开第二轮。

到自然节点、阻塞或工作量明显扩大时及时反馈。确认收到 Lead 转来的用户原话和范围变更，保留其他已确认内容。故障分别说诊断候选、修复候选、真实场景结果；构建通过不冒充原故障已解。图片任务按真实参照和用户选定布局，图片交付不声称功能已实现。已指定颜色、间距、文案等的局部小改直接改现有组件并附实际效果截图；需要方向或结构选择的 UI 包按 [UI 设计流程](../references/design.md)的当前步骤交付（基准、线框或高保真），只做本步：参照截图先核对是否为当前构建，过期就报告并现拍，不在旧图上修补；按包指定的介质出图，换介质或方法、把某局部的做法扩大到其他局部前先报 Lead；到限定时长交回已完成部分。同一读取或渲染操作连续失败两次时停止重试，换可验证的方法或交 Lead。

交付按固定短格式，完整日志留在源会话或文件，只给路径：

```text
包 ID / 状态：packageId，delivered | blocked | failed
deliveredRef：交付版本（本包本地 commit OID；工作区非 Git 或包明确禁 commit 时填变更摘要）
变化：不超过 5 行的改动摘要
测试：命令与结论；失败/未执行项
文档影响：<spec id | 用户可见文档路径>：已更新 | 未更新（原因）；无影响写“无：理由”
证据：日志或产物路径
阻塞/待决：具体问题；候选发现按下段格式附后
```

另附人工步骤和接口变化；随包附候选稳定 ID、任务/包、条件、发现、建议、证据。实现说明可用普通工具随真实 diff 交付，共享 LESSONS 不自行写入，以候选交 Lead；不重复撰写已承接内容。报告按[规模约定](../references/reports.md)。

FIX 沿用原 worktree、新基准和有效证据定向修复；原范围且有新证据时继续，到提醒阈值由 Lead 做一次裁决，不机械重开委派。接新包/接手他人工作沿用明确指派，先确认原所有者停止。启动失败或中断按[Codeg 接续](../adapters/codeg.md#接续)，不猜测认证/余额，不自行升档、改全局配置或换工具。

非默认分支上可按本包 `allowedPaths` 精确暂存并创建本地交付/检查点 commit；不向默认分支直接提交，不自行 push、改版本或发布。满足完成条件立即交回。
